# 一隅拼豆 App 1.1

本版本：
- MARD 標準 221 色（A/B/C/D/E/F/G/H/M，共 221 色）
- MARD 色號搜尋
- 圖紙編輯器與 221 色調色盤
- 庫存管理
- 作品照片
- PWA
- 深色／淺色模式切換
- 舊版圖紙與作品資料遷移

色卡 HEX 採公開 221 色對照資料作為螢幕顯示近似值；實體豆可能受光線、螢幕與批次影響。

更新方式：將 index.html、app.js、style.css、sw.js、manifest.webmanifest、README.md 上傳到 GitHub Repository 並 Commit。


## 1.2.1 UI 修正版
- 品牌名稱改為「一隅拼豆」
- AI 圖紙可選相簿或相機；相簿不再強制開啟相機
- 圖紙編輯器新增放大、縮小、橡皮擦、一鍵清除
- 使用可愛圓體字體 Kosugi Maru（Google Fonts 可用時）


## 1.3 AI 圖紙辨識
- 瀏覽器內圖片分析
- 自動估算/指定 16/24/32/48/64 格
- 自動切格與平均取樣
- 以 MARD 色表最近色匹配
- 產生各色用量與庫存差額
- 套用後可逐格修正
- 支援旋轉 0/90/180/270 度


## 1.3.1 資料保存修正版
- 圖紙、庫存、目前作品狀態自動保存到 localStorage
- 關閉/重開網址後自動恢復
- 切到背景與離開頁面前自動保存
- 新增「備份我的資料」JSON
- 新增「匯入備份」
- 新增「清除全部資料」
- 完成/操作後立即保存


## 1.3.2 相簿選圖修正
- 改用 Android/Chrome 原生檔案選擇器
- 「從相簿選圖」不再透過 JavaScript 強制點擊隱藏 input
- 另外提供獨立「拍照」按鈕
- 支援 JPG / PNG / WebP
- 選圖後立即進入 AI 辨識預覽
