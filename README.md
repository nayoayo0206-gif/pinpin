# 拼豆工作室 App 1.0 原型

手機優先 PWA 原型，包含：
- MARD 色號資料庫（示範資料，可自行編輯）
- 圖紙 16/24/32/48/64 格編輯器
- 上色、橡皮擦式清除、Undo/Redo
- 色號用量統計與庫存不足提示
- 庫存增減
- 作品照片上傳與保存
- 本機 localStorage 保存
- PWA Service Worker

注意：目前 AI 圖紙辨識是 UI 入口與流程原型，尚未連接真正的視覺模型；MARD 色號表也是可編輯的示範資料，不宣稱為官方完整色卡。

使用：
1. 將資料夾放到任何靜態網站主機，或用本機 HTTP server 啟動。
2. 手機瀏覽器開啟 index.html 所在網址。
3. 可加入手機主畫面。

下一階段可接：真正 AI 圖紙辨識、MARD 完整色表匯入、圖片自動格線偵測、雲端帳號同步、作品與圖紙關聯、CSV/Excel 匯出、購買清單。
